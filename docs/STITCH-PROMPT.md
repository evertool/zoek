# 得闲开台 — Stitch 设计需求描述

> 本文档用于指导 Stitch 完成微信小程序全量页面 UI 设计。
> 同时上传 PRD.md 作为产品逻辑参考。请结合两份文档设计。

---

## 关键约束

1. **这是微信原生小程序，不是 H5 网页。**
   - 设计宽度 750rpx（等价 iPhone 6 的 375pt）
   - 不需要浏览器地址栏、返回按钮等 Web 元素
   - 顶部导航栏为自定义模式（`navigationStyle: custom`），页面内容顶到状态栏下方
   - 右上角有微信强制保留的胶囊按钮（⊕ 和 ●●●），设计时右侧留出安全距离
   - 底部有微信原生 TabBar，4 个标签：牌局 | 雀友榜 | 开台记录 | 我

2. **使用 Lottie 动画**
   - Slogan 弹出、徽章点亮、麻雀牌翻面、连胜火焰等场景使用 Lottie JSON 动画
   - 动画文件需轻量（单个 < 50KB），适配小程序包体积限制
   - 不用 GIF / 视频，只用 Lottie

3. **设计风格由 Stitch 自由发挥。** 不限定色系和视觉风格，请根据产品调性自行判断最佳设计方向。参考方向：麻雀、粤语口语、社交趣味、轻松对局。

## 产品简介

得闲开台是一款粤语向的麻雀牌局积分记录小程序。用户一键开台，邀请雀友扫码入台，每人自己提交本局分数，系统自动零和校验，锁定后不可篡改。支持补分退分修正、散台结算排名、历史记录翻查。

核心流程：登录 → 一键开台 → 分享二维码 → 扫码入台 → 开始计分 → 每局各自入分 → 全员核对 → 确认锁定 → 下一局 → 散台结算

## Slogan 动画系统（核心亮点）

这是本产品最具特色的功能，贯穿全流程的粤语趣味动画，需要重点设计。

### 1. 首页品牌 Slogan

首页顶部品牌区，每次进入随机轮换一条：

- 得闲开台，唔好放飞机
- 得闲开台，雀友集结
- 得闲开台，今晚你话事
- 得闲开台，打牌唔使争拗

### 2. 等人入台 Slogan

台间页等人期间，根据缺人数弹出对应 Lottie 动画 + Slogan：

| 缺人数 | Slogan | 动画场景 |
|---|---|---|
| 缺 3 人 | 唔够脚，搵脚开台 | 一张麻雀牌孤单地转来转去 |
| 缺 2 人 | 叫埋朋友开台 | 两张牌向中间靠拢但还差两张 |
| 缺 1 人 | 三缺一，等紧你 | 三张牌排好，第四个位置空着闪烁 |
| 人齐 | 人齐，开台 | 四张牌整齐叠好，开心弹跳 |

### 3. 每局输赢 Slogan

每局锁定后，赢家和输家分别弹出不同的 Lottie 动画 + Slogan：

**赢家 Slogan（得分 > 0）**：

- 麻雀台上无父子
- 三八廿四，行街睇戏
- 牌品好，手气自然好
- 杠上开花，好运加码
- 今晚食糊，唔好执输
- 西风一起，越打越有
- 今晚唔饮汤，只打麻雀
- 牌运在手，赢到拍手
- 自摸三家，今铺话事
- 今铺食糊，全场赢家

> 赢家动画方向：麻雀牌翻转出红中字、金币飘落、烟花庆祝等积极向上风格

**输家 Slogan（得分 < 0）**：

- 麻雀可以输，牌品唔可以输
- 输马唔输阵，开台要有品
- 卫生麻雀，开心最紧要
- 打麻雀啫，唔好咁认真
- 今铺手气一般，下铺翻盘
- 俾你赢先，留啲好运俾下铺
- 小输无伤大雅，开心最紧要
- 今铺暂时落后，下一局逆风翻盘
- 输嘅系分数，赢嘅系朋友相聚嘅快乐
- 牌场得失平常事，下次开台再较量
- 今铺小输，下次翻盘
- 运气稍欠，再战一局
- 暂处下风，下铺逆袭

> 输家动画方向：麻雀牌轻轻倒下又竖起来、拍拍肩膀、下一局加油等温暖安慰风格，不要消极负面

### 4. 中场大赢家标记

牌台进行中 ≥ 10 局时，标记当前积分最高者为「大赢家」：

- 超过 10 局，大赢家暂露头角
- 十局过后，今晚话事嘅系你

> 动画方向：皇冠戴在麻雀牌上、火焰特效、聚光灯打下来

### 5. 散台结算 Slogan

牌台结束时，根据最终排名弹出：

| 排名 | Slogan |
|---|---|
| 第 1 名 | 今晚大赢家，全场话事 |
| 第 2 名 | 棋逢对手，虽败犹荣 |
| 第 3 名 | 下次开台再较量 |
| 第 4 名 | 今铺唔如意，下次翻盘 |

> 第 1 名配庆祝动画（彩花、皇冠），其余配鼓励性动画

### 6. 一家赢三家特殊 Slogan

当某局一人赢、其他所有人都输时弹出：

- 自摸三家，今铺话事！
- 今铺食糊，全场赢家！

> 动画方向：一张大牌居中发光，其他三张牌被吹飞

## 徽章系统

排行榜和结算页展示的成就徽章，需要设计对应图标：

| 徽章 | 条件 | 视觉建议 |
|---|---|---|
| 雀神 | 累计胜场 ≥ 50 场 | 麻雀牌组成的皇冠/神坛 |
| 连胜王 | 连续 3 场第 1 | 火焰连击效果 |
| 大翻盘赢家 | 单场从负转正 ≥ 30 分 | 逆风翻盘、牌面翻转 |
| 今晚手气王 | 单场 ≥ 10 局且积分最高 | 发光麻雀牌、锦鲤 |
| 稳如泰山 | 局间积分波动极小 | 稳固的牌堆、山形 |
| 常客 | 累计参与 ≥ 20 场 | 麻雀牌集合 |
| 铁脚 | 累计参与 ≥ 100 场 | 金色奖杯/勋章 |

## 需要设计的页面清单（共 10 页）

### 1. 首页（牌局 tab）

- **未登录态**：品牌视觉 + Slogan + 微信登入按钮
- **已登录态**：
  - 顶部品牌区 + 随机品牌 Slogan
  - 开台入口（大卡片，一键创建，无需填表）
  - 进行中牌台列表（台名、状态、局号、人数）
  - 空状态提示

### 2. 台间页（room）

- 深色主视觉头部卡：台名、状态（组台中/计分中/已结束）、成员数 x/4、当前局号
- 成员列表：头像 + 昵称 + 台主标记 + 你标记
- 微信二维码展示区
- 等人时弹出对应缺人数的 Lottie Slogan 动画
- 操作按钮：开始计分 / 取消牌台 / 散台
- ≥ 10 局时顶部显示大赢家标记

### 3. 计分页（score）

- 顶部状态条：第 N 局 · 已完成 M 局 · 已入 x/y
- 分数输入区：大号数字输入
- 提交按钮
- 核对态（review）：列出每人本局分数 + 总和 + 确认锁定按钮
- 锁定后弹出赢家/输家 Lottie Slogan 动画
- 底部操作：下一局 / 补分退分 / 散台

### 4. 补分退分页（adjustment）

- 类型选择：补分（红色块）/ 退分（绿色块）
- 对方选择列表
- 金额步进器
- 原因输入

### 5. 结算页（settlement）

- 共完成 N 局
- 排名展示：第 1-4 名，带奖牌色（金/银/铜）
- 每人最终积分
- 徽章展示
- 散台结算 Slogan Lottie 动画
- 私密分享按钮

### 6. 开台记录（tab）

- 月份分组列表
- 白卡行：台名 + 局数 + 我的得分（正负着色）
- 右上角徽章标记

### 7. 单场详情（detail）

- 逐局时间线（局号用麻雀牌样式）
- 每局每人分数
- 调整记录卡片
- 最终积分汇总

### 8. 雀友榜（tab）

- 玩家排名列表
- 展示：场次、胜场、前三率、平均名次
- 徽章展示（最多 3 个，超出折叠）
- 统计周期切换（近 30 天）

### 9. 我的（tab）

- 顶部个人卡：头像 + 昵称
- 累计徽章总数
- 设置列表
- 关于得闲开台

### 10. 入台页（join）

- 扫码后进入
- 牌台预览卡（台名、台主、已入人数）
- 确认昵称 + 入台按钮
- 人齐时弹出「人齐，开台」Lottie 动画

## 动画需求汇总

| 场景 | 动画类型 | 时长 | 触发条件 |
|---|---|---|---|
| 首页品牌 Slogan | Lottie 横幅滑入 | 300ms | 进入首页 |
| 缺 3 人等人动画 | Lottie 弹窗 | 2.5s | 有人入台时检查缺数 |
| 缺 2 人等人动画 | Lottie 弹窗 | 2.5s | 同上 |
| 缺 1 人等人动画 | Lottie 弹窗 | 2.5s | 同上 |
| 人齐动画 | Lottie 弹窗 | 2.5s | 人齐或开始计分 |
| 赢家 Slogan | Lottie 弹窗 | 3s | 本局锁定后得分 > 0 |
| 输家 Slogan | Lottie 弹窗 | 3s | 本局锁定后得分 < 0 |
| 一家赢三家 | Lottie 特殊弹窗 | 3s | 一人赢全部 |
| 中场大赢家 | Lottie 横幅 | 3s | ≥ 10 局每 5 局刷新 |
| 散台结算 | Lottie 弹窗 | 不自动消失 | 牌台结束 |
| 徽章点亮 | Lottie 微动画 | 500ms | 获得新徽章时 |
| 麻雀牌翻面 | Lottie 翻转 | 400ms | 局号展示、分数锁定 |

## 注意事项

1. 所有文案使用粤语口语风格，不要用普通话
2. 品牌名固定为「得闲开台」，不要出现其他名称
3. 不涉及现金、金额、付款等元素，只有积分
4. 麻雀牌是核心视觉母题，可自由发挥设计风格
5. 赢家动画要积极正向，输家动画要温暖安慰，不要消极负面
6. 所有页面底部需留出 TabBar 高度安全距离（约 100rpx）
7. 页面顶部需留出状态栏高度安全距离（约 88rpx）
8. 右上角需留出胶囊按钮宽度安全距离（约 200rpx）
