## 一、产品概述

### 1.1 产品名称

- 中文名: **雀记**
- 英文名: **zoek** (取自荷兰语 "zoek / zoeken"，意为"寻找/查找"，寓意查找好友、记录战绩)

### 1.2 产品定位

一款面向麻将爱好者的 **轻量级记分工具** 微信小程序。不追求复杂番种分析和自动算分，聚焦"快速手动记分、底牌校验防错、清晰统计、好友互动"四大核心场景，让牌友聚会时随手打开即用，打完就能看到结算。

### 1.3 设计理念

- **玩家自主记分**: 不内置番种引擎，玩家自己输入每局分数，灵活适配各地规则
- **底牌校验防错**: 桌主开桌时选填底分，系统据此校验每局记分是否合理（零和校验）
- **极简操作**: 打完一局，10 秒内完成记分
- **清晰结算**: 自动汇总，盈亏一目了然，不怕算错账

### 1.4 目标用户

| 用户画像 | 占比(预估) | 核心诉求 |
|---------|----------|---------|
| 休闲麻将玩家 | 70% | 简单记分，算清谁输谁赢多少 |
| 常聚牌友圈 | 25% | 战绩统计、历史回看、圈子管理 |
| 竞技/统计爱好者 | 5% | 数据分析、趋势图表 |

### 1.5 核心价值

- **快**: 打完一局，10 秒内完成记分
- **准**: 底牌校验，防止记错分
- **清**: 自动结算，盈亏一目了然
- **久**: 历史战绩永久保存，随时翻看，可分享到微信群

#### 2.3.2 底牌校验机制

这是雀记的核心防错机制。桌主开桌时选填底分，系统在玩家每局记分时自动校验：

| 校验项 | 说明 | 触发条件 |
|-------|------|---------|
| **零和校验** | 每局四家分数之和必须为 0（自摸/点和均满足） | 每局提交时 |

**校验不通过时的处理**：

```
零和校验不通过（四家之和 ≠ 0）
  → 弹出提示："四家分数之和为 X，应为 0，请检查"
  → 允许玩家强制提交（可能记的是花牌/跑马等附加分）
```

> **设计原则**: 校验是"提示"而非"拦截"，玩家可以选择强制提交，系统记录校验状态标记。

### 4.3 数据库设计 (核心表)

```sql
-- 用户表
CREATE TABLE users (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    openid      VARCHAR(64) UNIQUE NOT NULL,
    union_id    VARCHAR(64) UNIQUE,
    nickname    VARCHAR(32) NOT NULL,
    avatar_url  VARCHAR(512),
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_openid (openid)
);

-- 牌局表
CREATE TABLE games (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    creator_id          BIGINT NOT NULL,               -- 桌主(创建者)
    base_score          DECIMAL(10,2),                 -- 底分(元/分) NULL=不记金额
    status              TINYINT DEFAULT 0,             -- 0进行中 1已结束 2已删除
    total_rounds        INT DEFAULT 0,                 -- 总局数
    validation_warnings INT DEFAULT 0,                 -- 校验异常次数
    start_time          DATETIME,
    end_time            DATETIME,
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_creator (creator_id),
    INDEX idx_status (status)
);

-- 牌局玩家表
CREATE TABLE game_players (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    game_id     BIGINT NOT NULL,
    user_id     BIGINT,                               -- NULL=非注册用户(手动输入)
    nickname    VARCHAR(32) NOT NULL,
    seat        TINYINT NOT NULL,                     -- 1东 2南 3西 4北
    final_score DECIMAL(10,2) DEFAULT 0,              -- 最终盈亏
    UNIQUE KEY uk_game_seat (game_id, seat),
    INDEX idx_game (game_id),
    INDEX idx_user (user_id)
);

-- 每局记录表
CREATE TABLE rounds (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    game_id             BIGINT NOT NULL,
    round_number        INT NOT NULL,                  -- 第几局
    win_type            TINYINT,                       -- 0自摸 1点和 2流局 NULL=未标记
    winner_seat         TINYINT,                       -- 和牌者座位 NULL=流局/未标记
    loser_seat          TINYINT,                       -- 放炮者座位 NULL=自摸/流局/未标记
    scores              JSON NOT NULL,                 -- 四家本局得分 {"1": 16, "2": -16, "3": -8, "4": 0}
    validation_passed  TINYINT DEFAULT 1,             -- 校验是否通过 0异常 1正常
    validation_msg     VARCHAR(256),                   -- 校验异常说明
    note                VARCHAR(256),                  -- 备注
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_game (game_id),
    INDEX idx_round (game_id, round_number)
);

-- 圈子(常打好友组)
CREATE TABLE circles (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
```

### 4.4 记分校验逻辑 (核心)

```go
// 记分校验器伪代码
type ScoreValidation struct {
    Scores    map[int]float64  // {座位: 分数}
    BaseScore float64          // 底分
}

type ValidationResult struct {
    Passed  bool
    Message string
}

func (v *ScoreValidation) Validate() ValidationResult {
    // 零和校验: 四家分数之和 = 0
    sum := 0.0
    for _, score := range v.Scores {
        sum += score
    }
    if sum != 0 {
        return ValidationResult{
            Passed:  false,
            Message: fmt.Sprintf("四家分数之和为 %.1f，应为 0", sum),
        }
    }

    return ValidationResult{Passed: true}
}
```
