排位升降星规则详解

一、胜负判定准则：
四人麻雀开台完局时，以最终系统结算净番分为基准，番数为正且位列前两位即算为本场获胜，获 1 颗基础星。

二、连胜额外加星规则：
• 连胜达到 3 ~ 5 场：每次胜局结算额外增派 1 颗星（共计 +2 星）。
• 连胜达到 6 场及以上：进入超神状态，每次胜局结算额外增派 2 颗星（共计 +3 星）。

三、低段保护机制：
九品（青铜级）玩家全程享有「护雀令」，输局不扣星、不掉段。自四品（铂金级）开始，输局均扣除 1 颗星，当前小段为 0 星再输则掉至下个段位。
