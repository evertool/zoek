## 一、名称

### 主名称：雀友记

| 项目 | 内容 |
|---|---|
| 全称 | 雀友记 |
| 粤语读音 | zoek³ jau⁵ gei³ |
| 拼音 | què yǒu jì |
| 英文/代号 | zoek |
| 含义 | 「雀友」= 麻将朋友；「记」= 记录。记录同雀友打牌嘅分数 |
| 定位 | 麻将牌局积分记录小程序（粤语用户向） |

### 备选方案

| 编号 | 名称 | 粤语意涵 | 特点 |
|---|---|---|---|
| A | **雀友记**（主推） | 雀友 = 麻将朋友 | 亲切、好记、搜索冲突少 |
| B | **打雀记** | 打雀 = 打麻将 | 动感强、口语化 |

## 三、小程序介绍

### 简短版（一句话，用于小程序搜索摘要）

> 粤语麻将记分神器，自己记自己嘅分，零和校验唔使争拗。

### 标准版（用于小程序详情页）

> 雀友记系专为粤语朋友打造嘅麻将牌局积分记录工具。
>
> 唔使纸笔，唔使脑记，每位玩家自己提交本局分数，系统自动校验零和——总和唔系零就锁唔到局，咁就唔使争啦！
>
> 功能特色：
> - 开台组局，扫码入台，2-4 人随时开局
> - 每人只记自己嘅分，公平公正
> - 全员提交后复核，确认无误先锁定
> - 打错咗唔惊，锁定后可以补分退分修正
> - 牌局结束自动结算排名
> - 历史记录随时翻查，局局分明

### 语音搜索版（口语化，模拟用户搜索场景）

> 「打麻将点记分啊？」「有冇 apps 可以记录麻将分数？」
> 用雀友记啦！扫码入台，每人自己入分，自动核对零和，唔使再为争几多分嘈交。

## 四、头像设计指引

### 设计方向

| 项目 | 说明 |
|---|---|
| 风格 | 扁平简约，圆润亲切 |
| 主色 | #E6533C（麻将红 / 万子红） |
| 辅色 | #1A1A2E（深蓝底） |
| 尺寸 | 144×144px（微信小程序头像标准） |

### 设计元素

```
┌───────────────────┐
│                   │
│   ┌─────────┐     │
│   │  🀄     │     │  ← 麻将「中」字牌，红色，居中放大
│   │         │     │
│   └─────────┘     │
│                   │
│   雀友记           │  ← 底部品牌名，白色小字
│                   │
└───────────────────┘
     深蓝底色
```

### 头像设计说明

1. **主体**：一张麻将牌（「中」字红中），是最具辨识度的麻将符号
2. **色调**：深蓝底 + 红色牌面，对比强烈，小尺寸下仍清晰
3. **文字**：底部「雀友记」三字，字号小但可读
4. **留白**：四周留充足边距，避免列表缩略图中被裁切

### 提示文案（粤语版）

#### 记分流程

| 场景 | 提示文案 |
|---|---|
| 入分（正分） | `已入本局 +16 分，等紧其他雀友入分` |
| 入分（负分） | `已入本局 -16 分（今局扣 16 分）` |
| 入分（零分） | `已入本局 0 分` |
| 改分成功 | `已更新本局分数：+16 → +8` |
| 等紧入分 | `已入 2/3 位，仲有 1 位未入` |
| 进入核对 | `第 3 局已全部入完，请核对今局分数` |
| 核对通过 | `第 3 局已完成，今局总和为 0` |
| 零和失败 | `今局总和系 +8，请检查同修改自己嘅分数` |
| 下一局 | `第 4 局开始，请入本局分数` |
| 散台失败 | `第 4 局仲未完成，完成后先可以散台` |

#### 改分调整

| 场景 | 提示文案 |
|---|---|
| 发起补分 | `补分请求已发出，等紧李四确认` |
| 发起退分 | `退分请求已发出，等紧李四确认` |
| 收到补分 | `张三想补返 8 分畀你` |
| 收到退分 | `张三想退返 8 分畀你` |
| 确认成功 | `改分已生效：张三 -8 分，你 +8 分` |
| 拒绝成功 | `改分未生效，原来分数唔变` |
| 散台后更新 | `改分已生效，找数已更新` |
| 改分失效 | `改分已失效，原来分数唔变` |
