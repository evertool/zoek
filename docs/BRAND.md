## 三、小程序介绍

### 简短版（一句话，用于小程序搜索摘要）

> 粤语麻雀计分神器，自己记自己嘅分，零和校验唔使争拗。

### 标准版（用于小程序详情页）

> 得闲开台系专为粤语朋友打造嘅麻雀牌局积分记录工具。
>
> 唔使纸笔，唔使脑记，每位玩家自己提交本局分数，系统自动校验零和——总和唔系零就锁唔到局，咁就唔使争啦！
>
> 功能特色：
> - 开台组局，扫码入台，2-4 人随时开局
> - 每人只记自己嘅分，公平公正
> - 全员提交后复核，确认无误先锁定
> - 打错咗唔惊，锁定后可以补分退分修正
> - 牌局结束自动结算排名
> - 历史记录随时翻查，局局分明

### 语音搜索版（口语化，模拟用户搜索场景）

> 「打麻雀点计分啊？」「有冇 apps 可以记录麻雀分数？」
> 用得闲开台啦！扫码入台，每人自己入分，自动核对零和，唔使再为争几多分嘈交。

## 四、头像设计指引

### 设计方向

| 项目 | 说明 |
|---|---|
| 风格 | 扁平简约，圆润亲切 |
| 主色 | #E6533C（麻雀红 / 万子红） |
| 辅色 | #1A1A2E（深蓝底） |
| 尺寸 | 144×144px（微信小程序头像标准） |

### 设计元素

```
┌───────────────────┐
│                   │
│   ┌─────────┐     │
│   │  🀄     │     │  ← 麻雀「中」字牌，红色，居中放大
│   │         │     │
│   └─────────┘     │
│                   │
│   得闲开台         │  ← 底部品牌名，白色小字
│                   │
└───────────────────┘
     深蓝底色
```

### 头像设计说明

1. **主体**：一张麻雀牌（「中」字红中），是最具辨识度的麻雀符号
2. **色调**：深蓝底 + 红色牌面，对比强烈，小尺寸下仍清晰
3. **文字**：底部「得闲开台」四字，字号小但可读
4. **留白**：四周留充足边距，避免列表缩略图中被裁切

## 八、徽章体系

雀友榜和历史记录中展示的成就徽章，基于可解释的数据规则：

| 徽章 | 条件 | 说明 |
|---|---|---|
| 雀神 | 累计胜场 ≥ 50 场 | 长期胜率高，麻雀达人 |
| 连胜王 | 连续 3 场排名第 1 | 连胜势头强劲 |
| 大翻盘赢家 | 单场累计积分从负转正幅度 ≥ 30 分 | 逆风翻盘能力 |
| 今晚手气王 | 单场完成 ≥ 10 局且最终积分最高 | 当晚状态最好 |
| 稳如泰山 | 单场局间积分波动标准差 < 5 | 稳定发挥 |
| 常客 | 累计参与 ≥ 20 场 | 活跃玩家 |
| 铁脚 | 累计参与 ≥ 100 场 | 资深雀友 |

> 徽章计算规则必须可解释；数据不足时不显示徽章，不随机生成。同一场牌局可获多个徽章。
